# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。
- 发布批次：进入复核冻结结论、来源与相反证据；依据漂移后未批准批次失效（列受影响事实），已批准批次保留快照并标注必须复议。
- 双窗口发布/撤回按批次修订号裁决，后到动作保留冲突草稿与差异，不覆盖先到结果；回执重放幂等。
- 旧数据无修订号时升级为 R0 可追溯基线；写入失败从上一完整批次恢复。

端口为`18468`。

```bash
npm install
npm run build
npm run dev
```
