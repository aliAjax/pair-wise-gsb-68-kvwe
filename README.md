# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。
- **发布批次主线**：
  - 进入复核即冻结结论、来源与相反证据，复核只按这份冻结依据审阅（`src/services/batchEngine.ts`）。
  - 证据版本、结论或疑点在复核期间变化：未批准批次失效并逐项列出受影响事实；已批准/已撤回批次保留快照、状态不变，标注「必须复议」。
  - 两个窗口并发发布/撤回：后到动作按批次修订号裁决，落后即生成冲突草稿与差异，先到结果绝不被覆盖；草稿可丢弃或以当前修订号重提。
  - 无修订号的旧数据在启动时迁移为可追溯基线 `@r1`（证据同步标记）。
  - 批次提交带 pre-write 日志（WAL）：模拟写入失败时立即从上一完整批次恢复且不产生回执，刷新页面时启动恢复再次核对恢复点。
  - 回执幂等：同一回执重放只返回首次结果、累加重放计数，不新增审计。
  - 故障演练面板位于「编辑复核 / 故障演练」，可模拟写入失败与回执重放。

## 验证

```bash
npm install
npm run verify   # 15 项端到端裁决逻辑检查（冻结/失效/并发/复议/恢复/幂等）
npm run build
npm run dev
```
